# Крок (krok.courses)

Веб-приложение для практики белорусского языка с адаптивным подбором заданий и ИИ-помощником «Крокки».

Главный принцип: система смотрит, какие темы проседают или давно не повторялись, считает приоритет (Крок Score) и подкидывает нужные карточки. Можно ставить собственные цели и общаться с виртуальным репетитором в чате.

## Стек

- Next.js (App Router) + React + TypeScript
- PostgreSQL + Prisma
- Firebase Auth (вход по почте и через гугл (можно добавить и тот же Apple ID, но изучайте, если захотите добавить, требует лишних махинаций))
- DeepSeek API (проверка свободных ответов, объяснение ошибок, генерация планов и чат с Крокки)

## Как запустить локально

Node.js и Docker

1. Склонировать и поставить зависимости:
```bash
npm install
```

2. Скопировать `.env.example` в `.env` и закинуть свои ключи от Firebase и DeepSeek (`DEEPSEEK_API_KEY`). Строка `DATABASE_URL` уже настроена под докер.

3. Поднять базу и накатить миграции с сидами:
```bash
docker compose up -d
npx prisma migrate deploy
npm run db:seed
```

4. Запустить дев:
```bash
npm run dev
```

Вуаля, доступно на `http://localhost:3000`. (или другой порт из терминала, если первый чем-то уже занят у вас)

Для регистрации обязательно подключайте Firebase auth, иначе, развернув, дальше лендинга не зайдёте.

## Команды

- `npm run db:seed` – перезалить базовые навыки и задания (безопасно, старые юзеры не сотрутся)
- `npx prisma studio` – потыкать базу через браузер
- `npm test` – прогнать тесты (база должна быть запущена!!)
- `npm run build` – проверить что прод-сборка не падает
